# Repository meta / 仓库元信息

## About (EN)

Keep a Mac awake during long Grok Bot / Cursor agent runs. Prevents “Mac cannot connect” stalls when the screen sleeps, the machine idles, or (with caveats) the lid closes. Thin wrapper around macOS `caffeinate` + optional LaunchAgent.

## About（中文）

在长时 Grok Bot / Cursor Agent 任务期间保持 Mac 不休眠，避免息屏、空闲睡眠导致「本机 Mac 无法连接」或任务停滞。基于系统自带 `caffeinate`，可选 LaunchAgent 开机自启。合盖仍有限制，详见 README。
